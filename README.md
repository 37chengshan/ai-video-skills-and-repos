# AI Video · Agent Skills & Repos

一份给 **coding agent** 读的 AI 视频资源清单：开源仓库 + 可安装 skill + 三条本地沉淀文档。

目标是让另一台机器上的 agent 拿到这个 repo 就能自己选型、安装、出片，不需要问人。

> 三份 `docs/` 文档来自另一台机器，里面的绝对路径（如 `/Users/...`）请按你的环境替换。

## 给 agent 的入口

```text
读 ai-video-repos.md 第 0、1、2 节，按用户要做的片型选 1 个主仓 + 1 个参考仓。
安装前读目标仓的 LICENSE；装法见第 5 节。
需要更多候选读第 3 节（索引仓 133 条）。
输出任何成片前确认：素材可商用、AI 内容已标注、事实有出处。
```

## 三条经验（来自实际踩坑）

1. **代码许可 ≠ 素材许可。** MIT 的仓里也可能有 CC BY-NC 的素材；商用前逐项核。
2. **先做 5 秒测试。** 任何新风格先渲一个镜头的 3–5 秒，通过再并入整片，否则返工成本是十倍。
3. **分层选型。** 一主一备就够；同时装五套生产 skill 通常得到五个互相打架的流程。
